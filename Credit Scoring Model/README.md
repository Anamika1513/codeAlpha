# Credit Scoring Model Using Machine Learning

## 📌 Overview
This project predicts customer credit risk by classifying customers as **Good Risk** or **Bad Risk** using machine learning algorithms.

## 📂 Dataset
- **Dataset:** German Credit Dataset
- **Source:** [Kaggle](https://www.kaggle.com/datasets/uciml/german-credit)

## 🛠️ Technologies Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook

## 🤖 Algorithms Used
- Logistic Regression
- Decision Tree
- Random Forest

## 📊 Evaluation Metrics
Models are evaluated using Precision, Recall, F1-Score, and ROC-AUC.

**Best Model:** Random Forest

| Metric | Score |
|---|---:|
| Precision | 0.459 |
| Recall | 0.567 |
| F1-Score | 0.507 |
| ROC-AUC | 0.687 |
